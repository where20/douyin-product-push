## 关键设计决策

### 1. 价格尾图用 PIL 合成，不用 mmx 生成
**AI 生成中文必乱码**（FMDA 项目 2026-07-07 已踩过）。尾图核心信息是「¥40.9」
这种精确文案，只能后期叠加。分工：cover/scene → mmx（纯视觉，无文字）；
price → PIL。

### 2. 三图有叙事分工，不是随便 3 张
`cover(强视觉冲击) → scene(使用场景) → price(价格锚点)`
= 短视频「钩子→展示→逼单」在图文里的对应形态。

### 3. schema 断言只管**内容**，不管**产物**
初版把 `images` 写进必填字段 → build_feed 永远失败（出图产物这时还不存在）。
已修正：断言只查 `id/name/price/desc/color/copy/image_prompts/links`。

### 4. 违规词进断言
`最好/最佳/第一/顶级/极致/绝对/国家级/全网最低/根治/治愈/假一赔十/纯天然/100%有效`
等 20+ 词写进 `BANNED_WORDS`，文案/描述/商品名命中即 raise —— 平台判虚假宣传会扣分。

### 5. 文字截断按**像素宽度**，不按字符数
中文字宽差异极大（`¥` 和 `整` 差几倍），按字符数截断必然溢出边界。

### 实测中发现并修掉的 3 个真 bug

1. **价格串 `¥¥40.9`** —— 源数据已是 `¥40.9(...)` 又拼了 `¥`。
   修复：build_feed 里统一归一化成 `¥{数字}(规格)`。
2. **价格尾图文字溢出右边界被截断** —— 按字符数截断不够。
   修复：新增 `_fit_text()` 按 `draw.textlength()` 像素宽度截断。
3. **渐变遮罩导致白字压在包装印刷字上读不清** —— 改成实心深色带 + 40px 柔和过渡。

### 附带验证：图床同名重命名

## 自动化边界（说清楚）

**能自动化的**：选品、文案、三图出图、价格卡合成、链接核验、图床上传、发布清单。
**不能自动化的**：挂小黄车 + 发布 —— 需达人账号授权态，平台未开放个人号图文发布 API
（开放平台的 `video.create` 需**企业资质**入驻，个人开发者申请不到）。

所以这套东西的价值是：**把 90% 重复劳动自动化，只留最后一次点击**。
