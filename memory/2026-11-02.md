## 根因 (三条, 都在"自动派生字段"这一层, 不在出图脚本)
1. **`pool.color` 取到了主图的营销元素/背景色, 没分割商品本体**:
   - 100330127464 京东主图左半是**红底促销 banner** → 取到 `#782B33` (实为白/灰套装)
   - 100264350608 主图是食物/木色场景 → 取到 `#B36D47` (实为透明玻璃+黄盖)
   - 100036336847 主图是木色衣柜背景 → 取到 `#83634E` (实为米白布艺)
   → 京东主图**左边基本都是文案/促销角标**, 按整图取主色必然取错。
2. **`product_en` 从关键词猜品类材质**: 池里所有收纳箱都带"布艺"关键词,
   于是 100164783975 (实为塑料翻盖带轮箱) 也被写成 "fabric storage box" → mmx 画成布艺敞口箱。
3. **`build_feed.py::_color_en()` 低饱和红轴无兜底**: 低饱和 orange/yellow 有 beige 兜底
   (2026-10-29 为 #A7987A 加的), **红色漏了** → `#6C5B5B` 灰褐被映射成 "muted red" → 画出珊瑚红。
   池里 44 个商品有 5 个踩中这条 (100273287861 / 100208835137 / 10025897606594 / 100012600868 / 10151864952389)。
